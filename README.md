# ESB Studio Phone

Write, translate, make the banner for and publish ESB Power Line news from an Android phone. A separate project from the
desktop **ESB AI Studio** (`chiefhamim/esb-banner-studio`), which stays as it is. Scope: **Editorial + Graphics only**.
Outreach (bulk email) and the Video desk stay on the PC.

Status: scaffold. Every screen says "Planned" until it is built. See [docs/PLAN.md](docs/PLAN.md).

```bash
npm install
npm run dev      # http://localhost:5173, open it on the phone's browser or in Chrome's device mode
npm run build    # type-check + production build
npm run lint
```
